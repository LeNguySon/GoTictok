# Research notes

Decisions that took research live here, so nobody has to repeat the search.

- **When to write one:** whenever
  [research-first](../../.claude/rules/project/research-first.md) applies: a
  hard problem, a design decision with several reasonable answers, or a new
  dependency.
- **How:** copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD-<topic>.md`, or run
  `/research <problem>` in Claude Code.
- **Dependencies:** every direct dependency is listed in
  [dependencies.md](dependencies.md); the gate checks it.
